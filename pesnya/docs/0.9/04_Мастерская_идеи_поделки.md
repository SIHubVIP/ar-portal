# Мастерская «Идея»: идеи, спецматериалы и поделки

Дед Утиль и Кеша Вторсырьё продают **идеи** — чертежи 4 и 5 уровня для всех шести построек в боксе №40. Купить идею можно, как только откроется лавка идей на Помойке (задание «Вася, кто это?»). Строить по ней — после новоселья мастерской «Идея» в боксе №13 (финал «Своего дела»).

Для стройки нужны: сама идея, **спецматериалы** из ремиксов боссов и обычная цена уровня (монеты, доски, кирпич, цемент, провода).

## Спецматериалы

Каждая победа в ремиксе босса (пульт «РЕМИКС» у арены) даёт его спецматериал — без суточного лимита: Демо и Сингл — по 1, Альбом — 2, Платина — 3. Золотые синглы по-прежнему — раз в сутки с босса.

| Спецматериал | Откуда |
|---|---|
| Перо Пахана | ремикс Пахана (двор) |
| Бетон сцены | ремикс Шумодава (стройка) |
| Чип бессмертия | ремикс Кощея (серверная) |
| Чешуя Горыныча | ремикс Горыныча (набережная) |
| Спица колеса | ремикс Колеса (парк) |
| Тесто вечности | ремикс Теста (Чебуречная) |
| Барабан стиралки | ремикс Барабана (Прачечная) |
| Гаечный ключ «Атом» | ремикс Короля Хлама (Помойка) |
| Светочастицы | Рынок электроники (0.10) |

Тесто вечности и барабан стиралки ещё дают задания «Тесто вечности» и «Отстирать забвение» (0.8), а гаечный ключ «Атом» — «Утилизация отменяется».

## Скин «Тележка из «Ёжика»»

Награда за «Утилизацию отменяется»: Кеша поставил на тележку из гипермаркета «Ёжик» пропеллер. Скорость как у Избушки-Бас, сменить скин — в лавке идей или в мастерской.
