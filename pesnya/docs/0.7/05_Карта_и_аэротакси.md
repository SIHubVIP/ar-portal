# Карта Рубина и аэротакси «Ложка»

Новая кнопка с картой вверху справа (под журналом) открывает карту города Рубин: районы, места, кто там ждёт, где ремиксы и где сейчас Сингл Принц. Места из следующих обновлений тоже есть на карте — серыми точками с номером версии.

- **Золотая точка** — ты здесь. **Бирюзовая** — открытое место. **Серая с «?»** — откроется по сюжету.
- **«!» / «?»** рядом с местом — там кто-то ждёт тебя с заданием или наградой.
- **Фиолетовая «R»** — у арены стоит пульт ремикса. **Корона** — там сейчас Сингл Принц.
- **Аэротакси «Ложка»:** открывается наградой за «Воздушный патруль» Шустрого Пилота. Нажми на открытое место и «Лететь» — 25 монет. В бою кукурузник не садится.
