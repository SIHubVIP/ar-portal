# Предметы: уровни и характеристики

## Правила 0.6

- У каждой вещи есть **уровень**: надеть её можно только с этого уровня. Старые вещи — с 1-го по 10-й уровень (сила ÷ 5 + 1), легендарки с боссов — по уровню босса.
- **Сила** идёт в урон. Плюс у каждой вещи есть **характеристика своего слота** — чем реже вещь, тем больше: редкая +4, эпическая +7, легендарная +11.
- **Уникальные вещи** (награды соседей) дают ещё бонус сверху. Люба их не скупает.
- В сумке у каждой вещи кнопка **«Надеть»**. Если уровень мал — «С ур. N». Новые вещи надеваются сами, только если подходят по уровню и сильнее надетой.
- «Продать ненужное» у Любы не трогает надетое, уникальное и то, что нужно соседям для взятых заданий.

## Характеристики

| Характеристика | Слот | Что даёт |
|---|---|---|
| Ритм | голова | Расширяет окно «в бит»: +2 мс за единицу (максимум +50 мс). Базовое окно ±130 мс. |
| Удача | шея | Больше добычи (+1,5% к шансам за единицу) и монет (+1% за единицу). |
| Стойкость | тело | +12 к максимальному здоровью за единицу. |
| Скорость | ноги | +1,2% к скорости бега за единицу (на Избушке не действует). |
| Вайб | в руках | +2% к набору вайба за единицу — ХИТ! готов быстрее. |

## Мелочи и квестовые вещи

- **Семки** — Голубиная валюта. Баба Зина говорит, полезные.
- **Пёрышко** — Мягкое. Можно щекотать врагов (нельзя).
- **Крошки батона** — Остатки голубиной роскоши.
- **Гайка от самоката** — Самокат без неё скрипит. Теперь скрипишь ты.
- **Мешочек пыли** — Пылесос копил его годами.
- **Линза Тишинки** — В неё видно только тишину.
- **Кусок поролона** — Им обита вся Глушилка. Мягко и скучно.
- **Уши робо-зайца** — Ловят Wi-Fi и сплетни.
- **Микросхема тишины** — Отвечает за «ш-ш-ш». Больше не отвечает.
- **Перо чайки** — Пахнет рыбой и наглостью.
- **Кассета с джинглом** — Одна и та же песня. Тридцать раз подряд.
