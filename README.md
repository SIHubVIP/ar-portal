# AR Портал

Прототип AR-игры для Android: на реальном столе открывается портал, из него выпрыгивает
персонаж, и ты управляешь им джойстиком. Персонаж ходит по найденным поверхностям,
запрыгивает на книги и коробки и собирает звёзды.

## Как поставить на телефон

1. Открой вкладку **Releases** этого репозитория (справа на главной странице).
2. В последней сборке скачай файл `ar-portal-N.apk`.
3. Открой скачанный файл. Если телефон спросит, разреши установку из этого источника
   (на Xiaomi: «Настройки → Приложения → Особые разрешения → Установка неизвестных приложений»).
4. При первом запуске разреши доступ к камере. Если попросит, поставь «Сервисы Google Play для AR».

Новые сборки ставятся поверх старых, удалять ничего не нужно.

## Как играть

- Медленно поводи телефоном над столом, пока на нём не появятся белые области.
- Наведи центр экрана на стол и нажми **«Открыть портал»**.
- Джойстик слева — ходьба, **Прыжок** и **Кувырок** — справа.
- Высокие предметы (книга, коробка) персонаж не перешагнёт: на них надо запрыгнуть.
- **«Заново»** убирает портал, его можно поставить в другом месте.

## Как это устроено

- `GameRenderer.kt` — игровой цикл: поиск поверхностей ARCore, портал, физика, звёзды.
- `CharacterModel.kt` — персонаж из блоков и его анимация.
- `MainActivity.kt` — запуск ARCore, кнопки и подсказки.
- Сборка APK идёт автоматически в GitHub Actions после каждого изменения (`.github/workflows/build.yml`).

Персонаж «видит» реальный мир так: под каждой точкой, куда он идёт, игра пускает луч вниз
и находит ближайшую реальную поверхность — плоскость стола или точку карты глубины.
Если она выше ступеньки, это стена, и нужно прыгать.

# Башня на спине (`tower-run/`)

Раннер по крышам: собирай вещи в башню на спине, держи равновесие, сдавай добычу в воротах.

- Игра целиком в `tower-run/web/index.html` (Three.js). Её же можно открыть в браузере.
- `tower-run/app` — Android-обёртка: полноэкранный WebView с игрой внутри, работает без интернета.
- Сборка APK: `.github/workflows/tower.yml`. Готовый файл появляется в **Releases** как `bashnya-N.apk`.
  Перед сборкой игра проходит автотест в headless Chrome, скриншоты лежат в артефакте `smoke-test`.
